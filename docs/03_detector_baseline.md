# Базовый детектор

## Модель

В качестве базового детектора используется Faster R-CNN из `torchvision`. Его задача — найти bbox изоляторов, после чего crop передаётся в VLM или гибридный classifier+reporter блок.

Код модели:

- `src/model/fasterrcnn.py`
- `src/train.py`
- `src/eval.py`
- `src/infer.py`

Конфигурации:

- `src/configs/experiment/detector_baseline.yaml`
- `src/configs/train.yaml`
- `src/configs/eval.yaml`
- `src/configs/infer.yaml`

## Зафиксированные метрики

| Метрика | Значение |
|---|---:|
| mAP@[0.50:0.95] | 0.5664 |
| mAP@0.50 | 0.7597 |
| AR@100 | 0.7385 |

## Интерпретация

Для текущего исследовательского среза детектор достаточен, чтобы анализировать следующий блок. В Stage 4 сопоставление показало, что большинство GT-объектов имеют хорошие crop-кандидаты. Поэтому основной фокус смещён с улучшения detector baseline на качество семантической классификации crop.
