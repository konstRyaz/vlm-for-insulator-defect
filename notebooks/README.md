# Экспериментальные ноутбуки

В папке оставлены компактные notebook-запуски, полезные для воспроизведения основных веток:

| Файл | Назначение |
|---|---|
| `01_smoke_test.ipynb` | проверка окружения |
| `02_prepare_coco_for_kaggle_colab.ipynb` | подготовка COCO-данных для внешнего запуска |
| `03_stage3_dinov2_traincv_policy.ipynb` | DINOv2 train-CV coarse policy |
| `04_stage4_dinov2_qwen_hybrid.ipynb` | Stage 4 DINOv2+Qwen hybrid |

Полные локальные outputs в notebook не сохраняются; результаты сведены в `reports/intermediate/`.
