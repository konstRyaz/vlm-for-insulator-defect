# Данные

Исходные изображения и полные наборы разметки не включаются в репозиторий.

Ожидаемый формат после подготовки:

```text
data/
├── raw/
│   └── <dataset>/
└── processed/
    ├── train/
    ├── val/
    └── test/
```

Для детектора используется COCO-подобная структура: изображения и `annotations.json`
для каждого split. Скрипты подготовки находятся в `scripts/`.
