# Практическая ось развития

VLM полезна как слой развития системы вокруг DINOv2.

## Практические роли

- очередь ручной проверки;
- фильтрация ложных тревог;
- защитный фильтр для плохих вырезанных областей;
- коды причин для инспектора;
- будущие карточки проверяющего;
- проверка в режиме наблюдения без автоматического принятия решений.

## Главная мысль

VLM помогает не столько повысить обычную точность, сколько сделать схему обработки более управляемой и безопасной. Это особенно важно для практической системы инспекции, где цена разных ошибок различается.
