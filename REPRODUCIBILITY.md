# Воспроизводимость

## Статус

Этот репозиторий является чистой презентационной версией исследования. Он содержит код, конфигурации, финальные отчёты, компактные таблицы результатов и скрипты воспроизводимости. Он не является полным тяжёлым архивом всех временных выходных артефактов.

## Что можно воспроизвести из репозитория

- подготовку COCO-разметки и проверку данных;
- базовые проверки схемы «детектор -> вырезанная область»;
- оценку Stage 3/4 при наличии данных и компактных таблиц;
- диагностику top-k/oracle для Stage 10 при наличии CSV с предсказаниями;
- оценки Stage 12 по ручной проверке, плохим вырезанным областям и структурированному выводу при наличии соответствующих входных таблиц;
- проверку устойчивости Stage 14 при наличии полной таблицы данных;
- post-eval для Stage 15 E02 при наличии списка входных примеров и ответов VLM.

## Что требует внешних данных

- исходные изображения IDID;
- полные вырезанные области изображения;
- Kaggle-запуски с GPU для получения ответов VLM;
- сырые ответы VLM;
- сгенерированные временные выходные артефакты, не включённые в чистый репозиторий.

## Почему тяжёлые артефакты не включены

В Git не включаются:

- `outputs/`;
- `raw_outputs.jsonl`;
- изображения;
- временные каталоги Kaggle;
- архивы доставки.

Их отсутствие не означает, что эксперименты не проводились. Итоговые результаты зафиксированы в компактных CSV/MD в `reports/final/`.

## Минимальные проверки

```powershell
python scripts/smoke_imports.py
Get-ChildItem scripts -Filter *.py | ForEach-Object { python -m py_compile $_.FullName }
```

## Основной итог

Репозиторий воспроизводит методологию и содержит код для повторения ключевых расчётов, но для полного повторения всех чисел нужны внешние данные и среда запуска с GPU.
